Die technische Grundlage

Wie WissensWerk entsteht

WissensWerk entsteht Schritt für Schritt in einer lokalen Entwicklungsumgebung. Dabei geht es nicht darum, möglichst viele Werkzeuge einzusetzen, sondern die richtigen Werkzeuge für die jeweilige Aufgabe zu haben.

Joomla bildet die Grundlage des Projekts. Die eigentliche Entwicklung findet lokal statt: Eine Entwicklungsumgebung stellt Joomla bereit, der Code wird bearbeitet, SCSS wird während der Entwicklung automatisch zu CSS verarbeitet und Änderungen werden mit Git nachvollziehbar festgehalten.

So entsteht aus einzelnen Ideen, Entwürfen und Lösungen nach und nach eine funktionierende Website.

Laragon
Die lokale Entwicklungsumgebung

Laragon stellt die Umgebung bereit, in der WissensWerk lokal entwickelt und getestet wird. Joomla läuft dabei auf dem eigenen Rechner – unabhängig von einem produktiven Webserver.

Visual Studio Code
Der Arbeitsplatz für den Code

Visual Studio Code ist die zentrale Entwicklungsumgebung für die Arbeit am Template. PHP, HTML, SCSS und JavaScript lassen sich hier bearbeiten, organisieren und direkt im Projekt verwalten.

Live Sass
SCSS wird zu CSS

Mit Live Sass werden die SCSS-Dateien während der Entwicklung automatisch in CSS übersetzt. Änderungen am Design lassen sich dadurch unmittelbar im Browser überprüfen, ohne die CSS-Dateien jedes Mal manuell erzeugen zu müssen.

Git
Änderungen nachvollziehbar machen

Git hält die Entwicklungsschritte fest. Änderungen können miteinander verglichen, auf frühere Stände zurückgeführt und als klar definierte Entwicklungsstände gespeichert werden.
