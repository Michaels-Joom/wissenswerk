# EV-000 Entwicklungsumgebung-Übersicht

Die Qualität einer Software entsteht nicht erst durch den geschriebenen Code, sondern beginnt bereits bei der Wahl der richtigen Werkzeuge.

Die Entwicklungsumgebung von WissensWerk wurde bewusst so zusammengestellt, dass sie einen strukturierten, reproduzierbaren und effizienten Entwicklungsprozess unterstützt. Jedes eingesetzte Werkzeug erfüllt dabei eine klar definierte Aufgabe und ist Teil der Gesamtarchitektur des Projekts.

Die folgenden Dokumente beschreiben die verwendeten Werkzeuge, ihre Konfiguration sowie ihre Integration in den Entwicklungsprozess. Sie sollen nicht nur die Einrichtung der Umgebung ermöglichen, sondern auch die zugrunde liegenden Entscheidungen nachvollziehbar machen.
