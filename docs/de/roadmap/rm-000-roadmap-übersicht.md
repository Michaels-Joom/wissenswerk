**Status:** Aktiv

**Projekt:** WissensWerk

## Zweck

Diese Übersicht bildet den Einstieg in die Roadmap-Dokumentation des WissensWerk-Projekts.

Die Roadmap beschreibt nicht nur geplante Arbeitsschritte, sondern wird während der Entwicklung an den tatsächlich erreichten Projektstand angepasst. Damit bleiben Planung und Umsetzung nachvollziehbar miteinander verbunden.

## Aktueller Projektstand

Die Grundlagen des Projekts sind abgeschlossen.

Dazu gehören insbesondere:

- Projekt- und Dokumentationsstruktur
- eigenständiges Joomla-Template
- Git und GitHub
- Entwicklungsumgebung
- SCSS-Entwicklungsworkflow
- Designsystem-Grundlagen
- Bootstrap-Integration
- Joomla Web Asset API
- JavaScript-Build mit Node.js/npm und Terser
- Header-Grundstruktur
- Footer
- Navigation mit MetisMenu
- Bootstrap Offcanvas

Die Entwicklung befindet sich damit in der praktischen Template- und Komponentenphase.

## Prinzip

Die Roadmap ist ein lebendes Planungsdokument.

Ein abgeschlossener Entwicklungsschritt wird nicht nur als erledigt markiert, sondern möglichst auch mit der zugehörigen Dokumentation und dem entsprechenden Git-Commit nachvollziehbar gemacht.
