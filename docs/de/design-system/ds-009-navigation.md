# DS-009 Navigation

## Ziel

Die Navigation ermöglicht eine klare Orientierung innerhalb der Website. Sie unterstützt den Benutzer dabei, Inhalte schnell zu finden und sich jederzeit im Informationsangebot zurechtzufinden.

## Architekturprinzip

> Die Navigation folgt einer konsistenten Struktur und verwendet ausschließlich definierte Komponenten und Design Tokens. Navigationselemente besitzen projektweit ein einheitliches 
> Verhalten und Erscheinungsbild.

## Gestaltungsprinzipien
- Die Navigation ist einfach und verständlich
- Navigationselemente sind konsistent aufgebaut
- Der aktuelle Standort ist jederzeit erkennbar
- Die Navigation unterstützt verschiedene Endgeräte
- Navigation folgt einer klaren Informationshierarchie
- Interaktionen sind eindeutig und vorhersehbar
  
## Wirkung der Navigation
| Bereich              | gewünschte Wirkung |
|----------------------|--------------------|
| Orientierung         | eindeutig          |
| Bedienung            | intuitiv           |
| Informationsstruktur | klar gegliedert    |
| Wiedererkennung      | konsistent         |
| Benutzerführung      | nachvollziehbar    |

## Navigationsrollen
| Rolle              | Beschreibung                                       |
|--------------------|----------------------------------------------------|
| Hauptnavigation    | Erschließt die Hauptbereiche der Website           |
| Sekundärnavigation | Ergänzt die Hauptnavigation                        |
| Breadcrumb         | Zeigt den aktuellen Navigationspfad                |
| Seitennavigation   | Unterstützt die Orientierung innerhalb einer Seite |
| Footer-Navigation  | Bietet ergänzende Links                            |

## Navigationsprinzipien
- Jede Seite ist über nachvollziehbare Navigationswege erreichbar.
- Navigationselemente behalten projektweit ihre Funktion und Position.
- Der aktuelle Navigationspunkt wird eindeutig hervorgehoben.
- Navigation unterstützt sowohl Maus- als auch Tastaturbedienung.
- Die Navigation tritt hinter den Inhalt zurück und unterstützt dessen Erschließung.
