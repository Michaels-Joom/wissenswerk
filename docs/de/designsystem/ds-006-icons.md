# DS-006 Icons

## Ziel

Icons ergänzen Texte und unterstützen die schnelle Orientierung. Sie dienen der visuellen Unterstützung und ersetzen keine textlichen Informationen.

## Architekturprinzip

> Icons werden zentral über das Designsystem bereitgestellt und konsistent verwendet. Darstellung, Größe und Abstände orientieren sich an den definierten Design Tokens.

## Gestaltungsprinzipien
- Icons unterstützen den Inhalt
- Icons ersetzen keine Beschriftungen
- Für gleiche Funktionen werden immer dieselben Icons verwendet
- Icons besitzen eine einheitliche Gestaltung
- Dekorative Icons werden sparsam eingesetzt
- Icons müssen barrierefrei eingesetzt werden

## Wirkung der Icons
| Bereich    | gewünschte Wirkung  |
|------------|---------------------|
| Navigation | schnell erfassbar   |
| Aktionen   | eindeutig erkennbar |
| Hinweise   | unterstützend       |
| Status     | sofort verständlich |
| Inhalte    | dezent ergänzt      |

## Iconrollen

| Rolle      | Design Token       |
|------------|--------------------|
| Standard   | ds-icon-default    |
| Small      | ds-icon-sm         |
| Large      | ds-icon-lg         |
| Navigation | ds-icon-navigation |
| Action     | ds-icon-action     |
| Status     | ds-icon-status     |
| Decorative |	ds-icon-decorative|

## Einsatzprinzipien
- Navigation verwendet konsistente Icons
- Statusmeldungen verwenden eindeutige Symbole
- Aktionen werden bei Bedarf durch Icons unterstützt
- Rein dekorative Icons dürfen keine Information transportieren
- Aussagekräftige Texte bleiben die primäre Informationsquelle
