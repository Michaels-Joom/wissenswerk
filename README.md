# WissensWerk

**Understand – Develop – Document.**

WissensWerk is a long-term learning and development project focused on the development of a modern Joomla template.

The project is not only about the finished template. What matters is the path to it: understanding technical relationships, developing solutions, testing them in practice, and documenting relevant findings in a way that makes them understandable and reusable.

---

## What is WissensWerk?

WissensWerk combines **source code, design system, technical architecture, and documentation** into a shared knowledge base.

The project is developed iteratively. Ideas are evaluated, solutions are implemented and tested, and adjusted where necessary. Not every consideration becomes part of the permanent documentation. The documentation focuses on the actual architecture, important decisions, and findings that remain relevant for future development.

WissensWerk is therefore also:

- a Joomla template project,
- a learning project,
- a practical development environment,
- and a personal knowledge base for future projects.

## Goal

The goal is not to complete a template as quickly as possible.

The aim is to create a project that makes it possible to understand **how an idea becomes a functional and maintainable solution**.

The project therefore focuses in particular on questions such as:

- How can a clean template architecture be developed?
- How can Joomla, Bootstrap, and custom development work together sensibly?
- How can design decisions be translated into technical implementations?
- How can maintainable and update-safe solutions be created?
- How can technical problems be investigated systematically?
- Which findings are also valuable for future projects?

Practical, tested solutions take precedence over purely theoretical assumptions.

## Principles

- Architecture before implementation
- Semantics before styling
- Clarity before unnecessary complexity
- Documentation as part of development
- Explain decisions and make them understandable
- Verify solutions in practice
- Preserve relevant experience and findings
- Do not modify Joomla core files
- Consider maintainability and update safety
- Develop iteratively and learn from practical experience

These principles are **guidance, not a rigid process model**. As an individual project, WissensWerk is deliberately developed in a pragmatic and iterative way.

## Documentation

Documentation is an essential part of WissensWerk.

The project particularly documents:

- architecture decisions,
- technical structures,
- design decisions,
- development foundations,
- relevant solutions to problems,
- practical findings.

The documentation is **not a complete development log**.

Temporary working papers, discarded ideas, and completed tasks do not automatically become part of the permanent documentation. Documentation primarily records information that has lasting value for understanding, maintaining, or further developing the project.

## AI Support

**This project is developed with the support of artificial intelligence.**

AI is used as a sparring partner for research, architecture discussions, source code development, documentation, and the analysis of technical approaches.

As a learning project, this exchange is particularly useful for understanding technical concepts, comparing different approaches, and building new knowledge.

Proposed solutions are not adopted without review. They are understood, tested in practice, and critically evaluated before becoming part of the project or its documentation.

AI neither replaces understanding nor practical testing. It supports the development process.

Responsibility for the architecture, source code, documentation, and the technical evaluation of the results remains with the author of the project.

---

## Philosophy

Good software is not created by good code alone.

It is created through **understanding, decisions, practical experience, and the willingness to question solutions again and again**.

WissensWerk therefore follows a simple idea:

> **Understand – Develop – Document.**

Understanding leads to a decision.  
The decision leads to an implementation.  
The implementation creates experience.  
Experience becomes knowledge.

And that knowledge should not be lost.
